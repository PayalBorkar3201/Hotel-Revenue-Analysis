
# Hotel Revenue, Occupancy and Cancellation Analysis

## Project Overview

This project is a hotel analytics application developed using Python, Streamlit, SQLite, Pandas and Plotly.

It analyzes hotel reservations, room inventory, revenue, occupancy and cancellations.

## Objectives

- Reconcile hotel reservation records.
- Identify overlapping bookings.
- Calculate room occupancy rates.
- Analyze hotel revenue.
- Calculate cancellation rates.
- Compare room categories and booking dates.
- Generate auditable summary reports.

## Features

1. Interactive Hotel Dashboard
2. Reservation Management
3. Occupancy Analysis
4. Revenue Analysis
5. Cancellation Analysis
6. Data Quality and Reconciliation
7. CSV Report Downloads

## Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- GitHub

## Dataset

The project uses five sample datasets:

- reservations.csv
- rooms.csv
- rate_plans.csv
- cancellations.csv
- calendar_events.csv

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py
